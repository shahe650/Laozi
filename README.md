# Laozi
Proofreading Laozi's Tao Te Ching

The PDF file is the scanned version. It is used as the source of truth.

The HTML file contains error from OCR. This project is to proofread it.

To add to Kindle, first upload the HTML file to Google Drive, then download to Kindle.

The end product HTML file is converted to EPUB format and uploaded to https://books.fo/document/cfdf8f5508a24338
